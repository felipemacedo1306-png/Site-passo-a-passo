Como Fazer Seu Próprio Site com IA e GitHub

Aprenda o caminho prático de pedir o código para a IA, criar sua conta no GitHub e colocar seu site no ar sem travar.

Como funciona: aqui você não contrata alguém para ficar fazendo tudo por você o tempo todo. Você aprende como fazer — gerando o código com IA, publicando de graça no GitHub e tirando dúvidas conforme a tela aparece.

Passo 1

Peça o código para a IA do seu jeito

Explique para a IA qual é o objetivo da página, o que precisa ter e como você quer que fique. Ela gera o código HTML pronto para você copiar.

Na prática: se não gostar de alguma cor, texto ou botão, é só pedir para ajustar.
Passo 2

Crie sua conta no GitHub e um repositório

Faça sua conta gratuita no GitHub, crie um repositório novo (deixando em Public) para guardar os arquivos do seu site.

Na prática: dá para fazer isso direto pelo celular ou pelo computador.
Passo 3

Crie o arquivo index.html e cole o código

Dentro do repositório, crie um arquivo chamado exatamente index.html, cole o código gerado pela IA e salve (Commit changes).

Na prática: o nome index.html é o que abre a página principal do site.
Passo 4

Ative o GitHub Pages para gerar o link

Vá em Settings > Pages, escolha a branch main e salve. Em poucos minutos o link do seu site fica disponível para abrir e compartilhar.

Na prática: travou em alguma tela? Mande print e pergunte o que fazer agora.
